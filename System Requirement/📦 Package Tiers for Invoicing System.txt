📦 Package Tiers for Invoicing System

🔐 Account Type, Ownership & Package Visibility

During registration, the user must choose one account type:

1. Workshop Admin
   - Intended for a user who owns or manages only one workshop.
   - Registration creates one workshop tenant and one admin account for that workshop.
   - The admin can view and manage the package tier subscribed for that single workshop.
   - The admin can manage only data, staff, clients, invoices, vehicles, and settings under that workshop.

2. Superadmin
   - Intended for a user who owns or manages multiple workshops.
   - Registration creates a parent superadmin account.
   - The superadmin can create or link multiple workshop tenants.
   - Each workshop must have its own workshop admin account created or assigned by that superadmin.
   - The superadmin can see only workshops and workshop admins related to him, meaning those he created or those explicitly linked to his account.
   - The superadmin must not see workshops, admins, billing, or operational data belonging to another superadmin.
   - The subscribed package tier is visible and manageable by the superadmin only, unless explicit billing access is delegated.

Package scope:
 - If the user registers as Workshop Admin, the package subscription belongs to that one workshop/admin.
 - If the user registers as Superadmin, the package subscription belongs to the superadmin parent account and covers the linked workshops according to the selected tier limits.
 - Package visibility, billing actions, upgrades, downgrades, and renewal information must follow this account scope.


🟢 Basic Tier (Starter – small workshops)
** Core Features
 - Clients: profiles, vehicle info, basic service booking, view/download invoices
 - Workshop Admin: create/send invoices, receipts, simple jobs, service orders, track unpaid invoices
 - Staff: job management, mark payments received
 - E-Invoicing (LHDN): generate/submit invoices, download with QR + IRN
 - Vehicle Management: add vehicles, record service history
 - System Core: authentication, notifications, search, file uploads
* Add-Ons
 - 📱 Mobile App: RM X/month (shared, standard branding).
 - Loyalty/Rewards module.
 - WhatsApp/SMS notification pack.
👉 Target: single-workshop admin accounts with 1–3 staff, cost-sensitive, only need compliance & basics.


🟡 Pro Tier (Growth – medium workshops)
* Includes everything in Basic, plus:
 - Workshop Admin:
     - Inventory management (stock, suppliers, purchase orders)
     - Reports & analytics (revenue, staff performance, client spend)
     - Client engagement (promotions, reminders, loyalty tracking)
 - E-Invoicing: audit/archive automation, credit notes & cancellations
 - Vehicle Management: service reminders, insurance/tax renewal reminders
 - System Core: multi-language, audit trail, mobile responsiveness
 - Mobile App: included (shared app, standard branding).
👉 Target: single-workshop admin accounts with 5–15 staff, needing automation, customer retention, and mobility.


🔴 Enterprise Tier (Custom – large / multi-branch)
* Includes everything in Pro, plus:
 - Superadmin Features
     - Multi-workshop management under one parent superadmin account.
     - Create, assign, suspend, and manage workshop admins for linked workshops only.
     - Billing/subscription control visible to the parent superadmin only.
     - Cross-workshop analytics for linked workshops only (churn, growth, top services).
     - API integrations (accounting, WhatsApp, ERP).
 - Workshop Admin: advanced dashboards, financial summaries, supplier integration
 - E-Invoicing: compliance sandbox/live toggle, bulk submissions
 - Vehicle Management: fleet analytics (most serviced brands, mileage patterns)
 - System Core: advanced notifications, multi-factor authentication
* Mobile Options
 - Shared app (included).
 - White-label app (custom branding, optional add-on at negotiated price).
👉 Target: multi-branch workshops, franchises, high-volume clients with compliance & integration needs.


🔌 Registration API Requirement
 - Provide an external registration API so another system can create accounts.
 - The API must accept account type: workshop_admin or superadmin.
 - For workshop_admin registration, the API must create one workshop tenant, one admin user, and the selected package subscription for that workshop.
 - For superadmin registration, the API must create the parent superadmin account, selected package subscription, and optionally initial linked workshops/admins if supplied.
 - API-created workshop admins must be linked to the correct superadmin when created under a superadmin account.
 - API validation must enforce the same uniqueness, ownership, package visibility, and tenant isolation rules as the web registration flow.
