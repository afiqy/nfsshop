6. 🔒 Fraud & Abuse Prevention
 - Workshop Name must be unique system-wide.
 - Workshop Address checked as secondary uniqueness.
 - If duplicate → no new workshop created, registrant flagged as staff.
 - Free Trial limited to one per workshop (tracked by name + address).
 - Staff cannot bypass subscription restrictions → only Owners can manage subscriptions.

8. 📑 Enterprise Registration Requirements
i. 🎯 Enterprise Onboarding
 - Enterprise plans are not self-service.
 - Only Superadmin can create Enterprise subscriptions.
 - Pricing is subscription-based (quarterly or annual, no monthly option).
 - Custom pricing range set by Superadmin at registration.

ii. 🛠️ Registration Flow
 - Superadmin Setup
     - Superadmin creates a new Enterprise account in the system.
     - Inputs:
        -> Subscription type: Quarterly or Annual.
        -> Custom pricing (if different from default Enterprise).
        -> Add-ons (white-label app, API access, dedicated support).
     - Generates Enterprise Owner (primary user) record with login credentials.
 - Enterprise Owner Email
     - System sends an onboarding email to Enterprise Owner.
     - Owner completes personal account setup (name, email verification, password, contact info).
 - Workshop HQ Setup (by Owner)
     - After first login, Enterprise Owner is required to enter HQ Workshop Information:
         -> HQ Workshop name.
         -> HQ Workshop address.
         -> Business registration number.
         -> Tax Identification Number (TIN).
         -> Services offered (repair, maintenance, inspections).
 - Superadmin Control
     - Superadmin has ability to switch into the HQ Workshop Admin view (impersonation) for support.
     - Used for troubleshooting, billing queries, and compliance checks

iii. 🔑 Subscription Handling
 - Subscription options: Quarterly or Annual only.
 - Auto-renewal enabled by default.
 - Cancellation rules:
     - Enterprise Owner may request cancellation, but subscription remains active until end of billing cycle.
 - Payment flow:
     - Standard payment gateway (Stripe/PayPal/etc.) integration.
     - Invoices generated under Enterprise subscription.

iv. 📂 Data Fields (Enterprise Extension)
 - In Subscriptions table:
     - plan_type = enterprise.
     - billing_cycle (quarterly/annual).
     - custom_price.
     - auto_renew (true/false).
     - enterprise_owner_id (the user who received onboarding email).
     - hq_workshop_id (linked after owner completes setup).

v. ⚙️ System Logic
 - Superadmin registers Enterprise subscription → defines plan & pricing.
 - Enterprise Owner receives onboarding email → sets up account.
 - Enterprise Owner logs in → must complete HQ Workshop setup.
 - Subscription activates immediately (no approval flow needed).
 - Superadmin can impersonate HQ Workshop Admin for support.

vi. 🔒 Key Differences from Basic/Pro
 - Basic/Pro = self-service registration.
 - Enterprise = Superadmin-controlled registration (top-down).
 - No free trial for Enterprise.
 - Pricing tied to subscription cycle (quarterly/annual).
 - Superadmin has ongoing visibility & support access.


** ⚖️ End-to-End Journey **
 - Landing Page → Feature highlights, CTA.
 - Pricing Page → Choose Basic, Pro, or Enterprise.
 - Registration Flow (role-based):
     - Owner (Basic/Pro) → Free Trial / Trial Run / Paid.
     - Enterprise → Application → Superadmin approval.
     - Staff → Invited or auto-flagged.
     - Client → Optional self-registration.
 - Dashboard Access:
     - Active → full access.
     - Expired → dashboard visible but modules locked; only subscription page active.
     - Staff in expired state → “Contact Admin” notice only.
